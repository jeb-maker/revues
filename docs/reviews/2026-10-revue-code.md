# Revue de code Revues — octobre 2026

Revue transverse **read-only** (Go / Svelte / CSS / usage mb / documentation) sur `main` à `6e2b71f` (post WP-030). Aucun code modifié ; chaque constat porte un statut unifié (Confirmé / Partiel / Doc drift / Choix intentionnel / Rejeté), une preuve fichier et une ligne de critique adverse.

## Synthèse

Le rewrite API-first est **fonctionnellement abouti et sain côté Go** : codegen OpenAPI / sqlc / TS en phase avec les sources (régénération = diff vide), aucun SQL hors `internal/store`, aucun `panic` hors tests, IDOR/CSRF testés sur les routes sensibles, `golangci-lint` v2.12 (config CI) à 0 issue. Les trois dettes majeures sont ailleurs : **(1)** le pont `mb-bridge.css` écrase les tokens mb avec des variables du shell legacy qui n'existent plus — les boutons primaires mb sont rendus sans fond (vérifié en navigateur) ; **(2)** la SPA n'a ni shell ni thème partagé (21 pages redéclarent `:global(body)`, 344 couleurs hex en dur, 23 pages répètent le garde `bootstrap()` → `/login`), ce qui explique les budgets éco à 94–95 % et relevés à chaque WP ; **(3)** la documentation agent (`AGENTS.md` lint v1.62 vs CI v2.12, `.cursor/rules/design.md`, skill `revues-ui-audit`, `decisions.md`, README vendor mb, `RBAC.md` routes) décrit encore la stack HTMX, donc **`./scripts/check.sh` ne peut pas passer en local tel que documenté** et les agents reçoivent des règles contradictoires. S'y ajoutent deux régressions de parité : emails « revue terminée » / « point assigné » jamais émis par l'API, et verrou optimiste `updated_at` absent sur `PATCH run_items`.
